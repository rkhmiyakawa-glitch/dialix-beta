DIALIX v1.0.67 適用手順

1. ZIPを展開します。
2. 通常どおり npm install を実行します。
3. npm run build でビルドします。
4. Vercelへデプロイします。

今回の変更
- 顧客一覧、ユーザー管理、リスト管理、レポート、シフト管理の一覧行を白と薄いグレーの交互色へ統一
- 期限超過、本日のリマインド、リマインド一覧、検索結果、リンク一覧も同じ交互色へ統一
- 管理ダッシュボードのランキング、期限超過一覧も同じ交互色へ統一
- リスト一覧カードも同じ交互色へ統一
- 期限超過、ロック、未出勤などの警告背景色は維持

Supabase SQLの追加実行は不要です。
