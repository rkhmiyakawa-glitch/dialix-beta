DIALIX v1.0.0 RC6.34 適用手順

1. ZIPを解凍します。
2. 解凍した中身を、GitHub Desktopで管理している dialix-beta フォルダへ上書きします。
3. GitHub Desktopで src/App.css が変更ファイルとして表示されることを確認します。
4. Summaryへ「RC6.34 date selection spacing adjustment」と入力します。
5. Commit to main → Push origin の順に実行します。
6. Vercelの最新デプロイが Ready になったら、公開画面を Ctrl + F5 で更新します。

Supabaseや環境変数の変更は不要です。
