DIALIX v1.0.0 RC6.26 適用手順

1. 現在のDIALIXプロジェクトフォルダをバックアップしてください。
2. このZIPを展開し、現在のプロジェクトへ上書きしてください。
3. 使用中の .env ファイルは削除・上書きしないでください。
4. プロジェクト直下で npm install を実行してください。
5. npm run dev を実行して表示を確認してください。

確認箇所
- 管理画面 > リスト管理：顧客管理ボタンと顧客一括操作欄がないこと
- 管理画面 > ダッシュボード：ランキングが期限超過リマインドより上にあること
- 勤怠画面：カレンダー操作欄がカレンダー下にあること
- 管理画面 > シフト管理：シフト登録操作欄がカレンダー下にあること
- 月間シフト一覧：選択日の勤怠状況がカレンダー下にあること

Supabaseの変更は不要です。
