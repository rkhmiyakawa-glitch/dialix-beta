DIALIX v1.0.0 軽量化版

ベース:
RC6.41 リマインド縦並び修正版

軽量化内容:
- リスト一覧の重複取得を15秒間まとめ、同時リクエストも1回に集約
- 架電結果保存後はリスト件数キャッシュを破棄し、表示更新を維持
- リマインド取得の重複クエリを削減（本日分を取得済みデータから抽出）
- リアルタイム通知が連続した場合の再取得を600ms単位で集約
- 非表示タブでのユーザー稼働更新と管理シフト定期更新を停止
- サイドバー時計の更新を毎秒から毎分へ変更
- CSV解析時に同じ行を項目数分だけ再解析していた処理を1回へ削減
- 勤怠管理のユーザー別・日付別検索をMap化し、大人数時の反復走査を削減
- 顧客プレゼンス操作の関数参照を安定化し、不要なEffect再実行を削減
- Supabaseライブラリを別チャンク化し、画面コードの初期解析負荷を分散
- ソースマップを本番出力しない設定を明示

適用:
- Supabase SQLの追加実行は不要
- 通常どおりGitHubへ上書きし、Vercelで再デプロイ

確認:
- npm ci 成功
- npm run build 成功
- ZIP破損チェック実施
