DIALIX v1.0.66

変更内容
- 期限超過リマインド一覧のカード内側にある囲み枠を廃止
- 本日のリマインド／リマインド一覧のカード内側にある囲み枠を廃止
- リンク一覧とリンク追加欄の内側にある囲み枠を廃止
- 管理ダッシュボードのランキング／期限超過リマインド内側の囲み枠を廃止
- 外側の立体カードは維持し、内側は余白と行の区切り線だけで統一

適用方法
1. 既存プロジェクトをバックアップします。
2. このZIPの内容で既存ファイルを上書きします。
3. npm install を実行します。
4. npm run build を実行します。
5. Vercelへ再デプロイします。
