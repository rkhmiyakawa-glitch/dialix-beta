DIALIX v1.0.45 適用手順

1. 現在のプロジェクトをバックアップしてください。
2. .git と使用中の環境変数ファイル（.env / .env.local など）を残します。
3. ZIPの中身をプロジェクト直下へ上書きします。
4. npm install を実行します。
5. npm run build が成功することを確認します。
6. GitHubへ反映し、Vercelへデプロイします。

- 白基調のプレミアムデザインを全画面へ適用
- 温かみのある白、深いチャコール、控えめなシャンパンゴールドで統一
- ボタン、入力欄、カード、表、タブ、余白、角丸、フォントを共通化
- 配置、機能、集計ロジックは変更なし
- v1.0.43のKPIリセット・元に戻す機能を維持
