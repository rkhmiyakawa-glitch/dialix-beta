DIALIX v1.0.0 RC6.41 適用手順

1. RC6.41のZIPを展開します。
2. 既存プロジェクトを展開したRC6.41の内容で置き換えます。
3. frontend運用の場合は、展開したファイル一式をfrontendフォルダへ配置します。
4. 既存の.envを引き続き使用します。
5. npm install を実行します。
6. npm run build を実行します。
7. GitHubへ反映し、Vercelへデプロイします。

確認項目
- 見込みのリマインド欄で、日付が上・時間が下に表示されること。
- 見込み留守のリマインド欄で、日付が上・時間が下に表示されること。
- 前確依頼のリマインド欄で、日付が上・時間が下に表示されること。
- 日付・時間の入力欄が横幅いっぱいに表示されること。

Supabase SQLの追加実行は不要です。
