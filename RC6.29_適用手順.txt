DIALIX v1.0.0 RC6.29 適用手順

1. 現在のプロジェクトをバックアップしてください。
2. このZIPを展開してください。
3. 展開した内容を既存プロジェクトへ上書きしてください。
   ※ .env / .env.local / node_modules は上書きしないでください。
4. プロジェクトフォルダで npm install を実行してください。
5. npm run dev を実行してください。
6. 管理画面 > シフト管理で以下を確認してください。
   - 月間シフト一覧とシフト登録のカレンダーが同じ見た目になっている
   - 「登録・編集するAP」と「日付を選択」が横並びになっている
   - 2つの枠の高さが揃っている

Supabase側の作業はありません。
