DIALIX v1.0.46 適用手順

1. 現在のプロジェクトフォルダをバックアップします。
2. .git と環境変数ファイル（.env / .env.local など）を残します。
3. このZIPの中身をプロジェクト直下へ上書きします。
4. npm install を実行します。
5. npm run build が成功することを確認します。
6. GitHubへ反映し、Vercelでデプロイします。
