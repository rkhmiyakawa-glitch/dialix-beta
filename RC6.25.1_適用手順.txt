DIALIX RC6.25.1 適用手順

1. このZIPを展開します。
2. 現在のプロジェクトフォルダをバックアップします。
3. 展開したファイル一式を現在のプロジェクトへ上書きします。
4. .env は現在使用中のものを残してください（ZIP内の .env.example ではありません）。
5. プロジェクト直下で次を実行します。

   npm install
   npm run dev

6. 管理者またはオーナーでログインします。
7. 管理画面 → ダッシュボード → 期限超過リマインドを開きます。
8. 「担当AP」プルダウンで「全AP」または各APを選択し、一覧と件数が切り替わることを確認します。

Supabaseで行う作業はありません。SQL Editor、テーブル、RLS、Edge Functionの変更は不要です。

注意：APの選択肢は profiles の有効な operator / sv の display_name、絞り込みは customers.ap_name を照合します。名前が一致しない顧客は、そのAPを選択した際に表示されません。
